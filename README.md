# Content Hub Comparison 🌐✨

**Compare Wikipedia, Grokipedia, and Britannica side by side with search and word frequency analysis.**

## Features
- **Ctrl+K Search** 🔍: Instantly search across all three platforms.
- **Three Vertical Panels** 📊: Side-by-side comparison of content.
- **In-Article Search** 🔎: Find words within articles and highlight matches.
- **Word Frequency Counter** 📈: See how often a word appears in each source.
- **Warm, Modern UI** 🎨: Cozy color grading and sleek design.

## Tech Stack
- **Frontend**: Next.js (React) + Tailwind CSS
- **Search**: Algolia/Elasticsearch (optional)
- **APIs**: Wikipedia, Britannica, Grokipedia
- **Hosting**: Vercel/Netlify

## Getting Started
1. Clone the repo:
   ```bash
   git clone https://github.com/anacondy/content-hub-comparison.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.
